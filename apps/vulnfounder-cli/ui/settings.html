新增或更新模型配置

一个配置会把同一模型绑定到所有标准阶段。更新已有名称会覆盖它的阶段绑定，但不会因页面留空而删除已保存的 API Key。

密钥不回显
API Key 仅写入本机配置文件（权限 0600）或由环境变量提供。请勿把密钥放入截图、日志或提交记录。接口地址只允许 http/https，且不能携带用户名或密码。
只能使用字母、数字、点、下划线和连字符。
可以复用已有服务商；留空 API Key 会保留该服务商原有密钥。
