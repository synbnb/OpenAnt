暴露面识别

连接开发板后，读取目标 Unix socket 的权限、SELinux 标签、监听状态和关联进程。首次探测始终只读；如果发现服务已配置但未启动，必须经过你的明确确认才会启动并重新侦查。

安全边界

设备命令由固定探测计划生成，浏览器输入只用于目标标准化，不会拼接 shell 字符串。启动服务是单独的、可审计的确认动作。

批量识别

每行输入一个 Unix socket 路径或 TCP/UDP 端点。设备 serial、执行模式、大模型和 RAG 选项沿用下方设置；系统按顺序执行，不会自动启动停止的服务。

支持命名 Unix socket、TCP 或 UDP；网络目标可写成“进程 协议 IP:端口”。

新建识别

输入 Unix 路径，或选择 TCP/UDP 并填写进程、IP 地址和端口。
