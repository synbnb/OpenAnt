# OH-WEB-LLM-REACHABILITY-OPTION-2026-08-24

## 实现内容

- 首页新增“LLM 可达性复核”复选框，默认关闭。
- 新增每个分析单元最多发送源码字节数，默认 `1500`，Web 端限制为 `256–32768`。
- 只有勾选复核后，字节数输入框才启用；未勾选时服务端忽略该值。
- Web 后端将选项保存到扫描 `meta.json`，并转发为 `--llm-reachability` 和可选的 `--llm-reachability-max-code-bytes`。
- 扫描详情的 LLM 可达性阶段会根据实际选项显示为已请求，而不是固定显示 `not_requested`。
- 将源码字节数控件改为带“字节/bytes”单位的紧凑输入框，移除容易造成误解的浏览器原生上下步进箭头；未勾选时以明确的禁用样式显示，勾选后恢复可编辑状态。

## 使用说明

在首页“执行选项”中勾选“LLM 可达性复核”。默认使用 `1500` 字节；长函数或入口信号出现在函数后部时，可提高到 `4096` 或 `8192`。该阶段会复核整个代码库，因此会增加模型调用和费用。
