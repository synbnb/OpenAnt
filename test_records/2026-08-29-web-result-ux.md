# Web 扫描结果可视化改造测试记录

## 测试目标

确认扫描阶段详情和独立产物查看器能够优先展示高价值信息，同时保留完整字段、原始 JSON、搜索和分页能力。

## 本次改造

- 扫描阶段“关键结果”区域增加阶段级一句话结论，并根据成功、跳过、待定、失败和漏洞候选使用不同的提示色。
- 阶段关键字段卡片增加风险语义色彩，避免所有数字使用同一种视觉权重。
- 独立查看器增加“优先关注的信息”摘要区，按产物类型提取结论、源码位置、入口/可达性、安全分类、统计和输出路径等字段。
- 完整字段改为默认折叠，支持一键展开或收起；原始字段和值没有删除或改写。
- 数组中的对象优先使用函数名、漏洞编号、ID 等作为条目标题，不再统一显示“第 N 项”。
- 漏洞结果列表优先显示被分析函数，SAFE/VULNERABLE 等判定作为旁边的摘要字段保留。
- 完整字段顺序优先显示结论、位置、安全信号，再显示其他字段。
- 完整字段采用按需生成：用户打开“完整字段”后才创建详细 DOM，避免大型产物首屏渲染过重。

## 使用方式

1. 在安装 Go 的环境执行 `cd apps/openant-cli && make build`，然后重启 Web 服务；页面模板通过 `go:embed` 嵌入二进制。
2. 在扫描详情页选择任意阶段，先查看“本阶段结论”和“关键结果”。
3. 点击阶段产物的“独立查看”。
4. 独立查看器先看“优先关注的信息”；需要审计全部内容时点击“展开全部字段”或打开“完整字段”。
5. 仍可切换到“原始 JSON”进行逐字段核对。

前端脚本和真实扫描产物结构兼容；信息展示从“所有字段平铺”改为“重点摘要 + 按需展开”，不会牺牲原始数据完整性。
