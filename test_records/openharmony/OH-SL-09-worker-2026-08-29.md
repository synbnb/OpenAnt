# OH-SL-09 worker 单阶段端到端测试记录（2026-08-29）

## 范围

验证 `SourceLocatorWorker` 能否在不访问网络、不执行 Git 的条件下，把持久化
session 依次推进到“等待用户确认”，并为每个阶段留下可审计产物。

## 测试输入

- 目标：`/dev/unix/socket/paramservice`
- OpenGrok：本地仿真客户端，返回带行号的 bind、accept、dispatch、connect、send
  和服务配置源码证据。
- Manifest：`tests/source_locator/fixtures/manifests/ohos.xml`，其中
  `base/startup/init` 映射到 `startup_init` 和
  `https://gitcode.com/openharmony/startup_init`。
- Git：未调用；确认阶段之前不允许拉取仓库。

## 执行命令

```text
../../.venv/bin/python -m pytest -q tests/source_locator/test_worker.py
../../.venv/bin/python -m pytest -q tests/source_locator
../../.venv/bin/ruff check core/source_locator openant/cli.py tests/source_locator
```
